# bayesian-network-sem-sapotaceae
Data and R scripts for Bayesian network and structural equation modelling analyses of phenotypic traits in Pouteria sapota and Chrysophyllum cainito.

# Bayesian Network and SEM Analysis of Phenotypic Traits in Sapotaceae

This repository contains data files and R scripts related to the study of phenotypic trait relationships in two Sapotaceae fruit species: *Pouteria sapota* (mamey sapote) and *Chrysophyllum cainito* (star apple).

## Project overview

The aim of this project is to investigate the dependence structure among fruit, peel, and seed traits using a combination of:

- Bayesian network structure learning
- jackknife-based stability assessment
- equivalence class inspection (CPDAG)
- structural equation modelling (SEM)

The study was designed as an exploratory analysis intended to generate biologically informed hypotheses about phenotypic trait relationships in these two species.

## Species included

- *Pouteria sapota* (mamey sapote)
- *Chrysophyllum cainito* (star apple)

## Repository structure

This repository is expected to include the following folders:

- `data/` — raw or processed phenotypic datasets
- `scripts/` — R scripts used for data preparation, network learning, stability assessment, and SEM fitting
- `results/` — output files generated during the analyses
- `figures/` — figures used in the manuscript or generated by the scripts

## Data

The phenotypic datasets will be added to this repository after final organisation and review.

A more detailed description of the variables, file structure, and data processing steps will be provided once the final datasets are uploaded.

## Code

The repository contains R code used to:

- import and prepare the datasets
- perform descriptive analyses
- assess univariate and multivariate normality
- learn Bayesian network structures using IAMB and Tabu search
- evaluate structural stability by leave-one-out jackknife resampling
- inspect equivalence classes through CPDAGs
- fit structural equation models based on biologically selected candidate networks

## Reproducibility

To reproduce the analyses, users will need:

- R
- the required R packages listed in the analysis script
- the phenotypic datasets once they are uploaded to the `data/` folder
