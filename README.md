# Bayesian Network and SEM Analysis of Phenotypic Traits in Sapotaceae

This repository contains the datasets, R script, and selected output files used in the study of phenotypic trait relationships in two Sapotaceae fruit species: *Pouteria sapota* (mamey sapote) and *Chrysophyllum cainito* (star apple).

## Project overview

The aim of this project is to investigate the dependency structure among fruit, peel, and seed traits using a combination of:

- Bayesian network structure learning
- jackknife-based stability assessment
- equivalence class inspection (CPDAG)
- structural equation modelling (SEM)

The study was designed as an exploratory analysis intended to generate biologically informed hypotheses about phenotypic trait relationships in these two species.

## Species included

- *Pouteria sapota* (mamey sapote)
- *Chrysophyllum cainito* (star apple)

## Repository structure

- `data/`: datasets used in the analyses
- `scripts/`: R script for descriptive statistics, Bayesian network learning, jackknife stability assessment, CPDAG inspection, and SEM fitting
- `output/`: selected output files generated by the analyses

## Data

The `data/` folder contains the phenotypic datasets used in the analyses reported in the manuscript. These datasets include measurements related to fruit, peel, and seed traits for the two Sapotaceae species considered in the study.

## Code

The `scripts/` folder contains the R script used to:

- import and prepare the datasets
- perform descriptive analyses
- assess univariate and multivariate normality
- learn Bayesian network structures using IAMB and Tabu search
- evaluate structural stability by leave-one-out jackknife resampling
- inspect equivalence classes through CPDAGs
- fit structural equation models based on biologically selected candidate networks

## Output

The `output/` folder contains selected files generated during the analyses, including descriptive summaries and model fit results used to support the manuscript.

## Reproducibility

To reproduce the analyses, users will need:

- R
- the required R packages listed in the analysis script
- the datasets available in the `data/` folder

The main analytical workflow is implemented in the R script available in the `scripts/` folder.
